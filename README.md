# MageMaze

MageMaze tem como premissa ser um jogo de bullet hell, inspirado no Realm Of The Mad God.

## Protótipo

Atualmente, os possíveis controles estão disponíveis:

- Controlar o jogador com as teclas `W`, `A`, `S` e `D`;
- Ligar/desligar tiros com o botão esquerdo do mouse;
- Dash com o botão direito do mouse;


## Funcionalidades

Já foi criado o level principal, onde há 3 variações de inimigos, que perseguem o jogador e atiram de formas diferentes. Cada um tem vida e pode dropar um item que aumenta a vida máxima do jogador.
